# Narrative Geometry

## Content of this git

- `./notebooks/` contains illustrative notebooks in the jupytext format (initiated by `jupytext --to py:percent <NOTEBOOK_NAME>.ipynb` they synchronized by `jupytext --sync <NOTEBOOK_NAME>.ipynb` (see more at [jupytext.org](https://jupytext.org/using/cli/))
- `./docs/notebooks/`contains html versions of these notebooks, generated by `jupyter nbconvert --to html --output=../docs/notebooks/<NOTEBOOK_NAME>.html notebooks/<NOTEBOOK_NAME>.ipynb`
